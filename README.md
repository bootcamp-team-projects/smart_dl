# Smart DL — 딥러닝 실습 및 모델 개발

Smart 팀 프로젝트의 딥러닝 관련 코드와 실험 결과를 관리하는 저장소입니다. 서비스에 활용되는 모델의 구조와 학습·평가 과정을 문서화하는 데 목적이 있습니다.

## 프로젝트 범위

- 학습 데이터 준비 및 전처리
- 딥러닝 모델 구성과 학습 실험
- 검증 데이터 기반 평가
- 모델 파일 및 추론 흐름 정리
- 앱·웹 또는 백엔드와의 연동을 위한 결과물 준비

실제 적용된 모델과 기능은 저장소의 코드 및 설정 파일을 확인해 구체적으로 작성해야 합니다.

## 기술 스택

- Python 기반 딥러닝 환경
- 딥러닝 프레임워크(실제 의존성 파일 확인 필요)
- 데이터 및 모델 파일

## 실행 방법

프로젝트에 포함된 의존성 파일과 노트북·스크립트의 실행 순서를 확인하세요. 데이터셋, GPU 요구사항, 모델 가중치가 별도로 필요하다면 준비 방법과 라이선스를 함께 기록해야 합니다.

모델 성능을 기록할 때는 데이터 분리, 평가 지표, 학습 설정을 명시하세요. 실제 실행으로 검증하지 않은 결과나 성능 수치는 기재하지 않습니다.
